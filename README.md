# Courier for Mac

**[Download Courier](https://github.com/mohstaf/courier-releases/releases/latest/download/Courier.dmg)**

Needs a Mac with Apple silicon and macOS 14 or later.

1. Open the disk image and drag Courier to Applications.
2. Open Courier. If macOS says it can't check it, open System Settings › Privacy & Security and click **Open Anyway** (only the first time).
3. Add your account: sign in with Google or Microsoft, or use an app password for any other mailbox.

Courier keeps itself up to date: new versions download in the background and go in the next time you quit it (Settings › Updates).
